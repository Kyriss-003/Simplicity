# HomeScreen UI Overhaul — Implementation Plan

## Goal
Transform the current 980-line monolithic `HomeScreen.tsx` into a polished, production-ready UI matching the reference image. Decompose into focused components, upgrade to vector icons, rebuild the sidebar, add Reanimated animations, and enhance the Scratch Pad with a real markdown toolbar.

## Decisions Made
- **Icon system**: Replace all Unicode emoji with `@expo/vector-icons` (MaterialCommunityIcons + Ionicons)
- **Capsule switcher**: Show on ALL screen sizes (not just mobile)
- **Sidebar**: Rebuild from scratch — Apple Notes/Bear/Obsidian style with search, folder tree, and theme footer
- **FAB**: Show on ALL screen sizes with Reanimated spring animation, hover expand (desktop), tap expand (mobile), auto-close on mouse-leave
- **Scratch Pad**: Rich markdown formatting toolbar (Bold, Italic, Heading, Lists, Code, Link, Preview)
- **Styling**: Keep `StyleSheet.create` + Theme tokens (no NativeWind migration)
- **Animations**: Install `react-native-reanimated` v3
- **Tasks/Events persistence**: Keep in-memory for now; note in AGENTS.md for future SQLite persistence

## Key Constraints
- All list items use strict flex rows (`flexDirection: 'row'`, `alignItems: 'center'`, fixed-size containers with `flexShrink: 0`, `flex: 1` text containers)
- Responsive: scale for mobile view with breakpoint at 768px
- Dark UI with theme tokens from `src/theme.ts`
- Offline-first: all note edits go to SQLite first
- No NativeWind/Tailwind — keep StyleSheet.create + Theme tokens
